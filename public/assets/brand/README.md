# ClanIntel brand assets

Original project mark: a gold outlined shield with an analytics graph. No game logo or character is used in the mark.

- `clanintel-mark.svg`: scalable header mark (64 x 64 viewBox, 44 x 44 display size).
- `/favicon.svg`: vector favicon.
- `/favicon.ico`: 16, 32, 48 and 64 px fallback icons.
- `apple-touch-icon.png`: 180 x 180 touch icon.

The wordmark uses HTML text, with Clan in the active theme text color and Intel in its warning/gold accent. Illustrations remain in the compressed artwork folder.
